# Forex Campaign Tracker

FX / CFDキャンペーンの参加状況、取引コスト、当選・還元額を管理する静的Webアプリです。

## 対応キャンペーン

- GMO外貨「毎日500名様に当たる！999円キャッシュバック大抽選会！」
- GMOクリック証券「ハズレなし！毎週最大4,000円が当たる抽選キャンペーン」
- GMOクリック証券「1アカウント連携 毎週25名様に10,000ポイント」

## 保存方式

記録データはブラウザの `localStorage` に保存されます。

- サーバーへの個人データ送信なし
- 証券会社のID、パスワード、口座番号は保存しない
- 同じURLでも、別端末・別ブラウザとは自動同期されない
- Safari等のサイトデータ削除で消える可能性があるため、定期的なJSONバックアップを推奨
- 「JSONを書き出す」「JSONを読み込む」で端末間移行・バックアップが可能

保存キー: `forexCampaignTracker.v1`

## GitHub Pages

ビルド不要の静的サイトです。GitHub Pagesでリポジトリの `main` ブランチ / root を公開元にすればそのまま動作します。

## ファイル

- `index.html` — 画面構造
- `styles.css` — UI
- `app.js` — キャンペーン判定・localStorage・集計・バックアップ

## 注意

キャンペーン条件は変更される可能性があります。実取引前に必ず各社公式ページを確認してください。このツールは記録補助であり、投資助言ではありません。
